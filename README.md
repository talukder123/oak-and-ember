# 🍽️ Oak & Ember

**Oak & Ember** is a static restaurant website built using **HTML and CSS**. The project focuses on creating a clean restaurant-style interface with a visually appealing layout, typography, colors, and content sections.

> ⚠️ This is a **static frontend project**. It is not interactive and is not responsive.

## ✨ Features

* 🍴 Restaurant-themed landing page
* 🏠 Hero section with restaurant branding
* 📖 Menu/content sections
* 🖼️ Food and restaurant imagery
* 📍 Restaurant information
* 🎨 Custom styling with CSS
* 📄 Multiple structured website sections

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 🚀 Getting Started

No installation or dependencies are required.

1. Clone the repository:

```bash
git clone https://github.com/talukder123/oak-and-ember.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
